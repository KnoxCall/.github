# KnoxCall

**Your apps hold a token. KnoxCall holds the key.**

Your code calls the API through KnoxCall, and KnoxCall injects the credential. Keys stay
encrypted in one place, and you can rotate or revoke them without redeploying.

[Website](https://knoxcall.com) · [Docs](https://docs.knoxcall.com) · [Live demo](https://knoxcall.com/demo) · [Discord](https://discord.knoxcall.com) · [Trust center](https://knoxcall.com/trust)

## SDKs

| Language | Install | Source |
| --- | --- | --- |
| Node.js | `npm install @knoxcall/sdk` | [sdk-node](https://github.com/KnoxCall/sdk-node) |
| Python | `pip install knoxcall` | [sdk-python](https://github.com/KnoxCall/sdk-python) |
| Go | `go get github.com/knoxcall/sdk-go` | [sdk-go](https://github.com/KnoxCall/sdk-go) |
| PHP | `composer require knoxcall/sdk` | [sdk-php](https://github.com/KnoxCall/sdk-php) |
| Ruby | `gem install knoxcall` | [sdk-ruby](https://github.com/KnoxCall/sdk-ruby) |
| Browser | `npm install @knoxcall/browser` | |
| React | `npm install @knoxcall/react` | |

The SDK repositories are read-only mirrors of our main codebase. Issues are welcome there;
pull requests are not merged. Guides for each SDK are at
[docs.knoxcall.com/sdks](https://docs.knoxcall.com/sdks/overview).

## Security

Report a vulnerability to **security@knoxcall.com**. Please don't open a public issue.
